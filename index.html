    ¿Cómo se calcula este aviso?

    Se toman las últimas muestras de las variables relevantes (partículas, física molecular y aceleraciones) y se comparan con su comportamiento de las horas previas usando la mediana y la desviación absoluta mediana (MAD), una medida robusta frente a picos aislados. Las coordenadas y el ángulo se muestran solo como contexto y no disparan el aviso. El aviso se activa cuando una o más variables relevantes presentan una variación sostenida (no un pico de un solo dato) que supera un umbral estadístico y un cambio mínimo. Los picos aislados, tanto al alza como a la baja, se evalúan por separado de los cambios sostenidos y pueden mostrarse como aviso de pico. Las variables relacionadas se agrupan para reducir el doble conteo de señales correlacionadas. Si faltan datos de canales esenciales, se informa una evaluación incompleta. Los umbrales son experimentales y requieren validación retrospectiva; el resultado no predice terremotos.

    Información de un estudio en desarrollo. Este aviso no proviene de una autoridad oficial ni de un organismo de alerta, y su hipótesis aún no ha sido validada científicamente. No lo use para tomar decisiones de seguridad; ante un sismo, siga los protocolos oficiales.
